# BYD-HVM-Live v1.5 — Experimental release

Independent PowerShell diagnostics dashboard for BYD Battery-Box Premium HVM. **Unofficial software. Not approved by BYD or intended as battery safety instrumentation.**

## What's new

- View per-cell balance-selection flags and their counts by module and tower alongside cell voltages.
- Show each tower's **reported** SOH, cumulative charge/discharge energy and signed current.
- Export `cells.csv`, `modules.csv`, `system.csv` and raw diagnostic captures, with appended v1.5 schema fields.
- Show estimated module voltage and power from cell voltages and common tower current (not measured independent module power).
- Improved serial identity checks, reconnection behavior, stale-reading handling and on-screen voltage-condition labels.
- English console UI, built-in help and self-tests; Windows PowerShell 5.1 and PowerShell 7 CI.
- Research notes on protocol limitations, offline firmware interpretation and HVM BIC hardware observations.

## Requirements and usage

Windows PowerShell 5.1 or PowerShell 7; existing compatible BYD RTU-over-TCP gateway, typically port 8080. Default configuration assumes three HVM towers and seven modules per tower; other layouts have only synthetic test coverage.

Download `BYD-HVM-Live-v1.5-EN.ps1` and run:

```powershell
.\BYD-HVM-Live-v1.5-EN.ps1 -SelfTest
.\BYD-HVM-Live-v1.5-EN.ps1 /?
.\BYD-HVM-Live-v1.5-EN.ps1 /YOUR_BATTERY_IP
```

## Validation and limitations

Automated Windows PowerShell 5.1/7 synthetic/simulator tests passed, and the decoder was checked against saved diagnostic payloads. Operation on one three-tower HVM installation was observed during October 2026. This is **experimental field validation, not a certified meter, universal compatibility guarantee, or safety verification**.

Balance flags indicate reported software selection/state, **not measured bleed current or confirmed hardware switching**. SOH is the BMS model's estimate, not an independent capacity measurement. The raw `Cal` field is **not** confirmed to mean an active calibration phase. Some voltage-condition warning bits can persist after cell voltage decreases, and exact service semantics are not established.

The monitor uses FC03 diagnostic reads and **one existing FC16 write to select diagnostic tower data**; it is therefore **not strictly read-only on the wire**. It does not request charging/discharging, reset SOC/SOH, change safety limits, flash firmware, or run service-unlock commands. Do not run it concurrently with BYD firmware updates or another reader that may interfere with selections.

Private logs, firmware binary images, IP addresses and controller serial numbers are not part of the release. Review your own logs before sharing.
